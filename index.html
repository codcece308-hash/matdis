📖 Apa itu Deret Geometri?

Deret Geometri adalah penjumlahan dari suku-suku barisan geometri, yaitu barisan yang setiap sukunya diperoleh dengan mengalikan suku sebelumnya dengan bilangan tetap yang disebut rasio (r).

Barisan → a, ar, ar², ar³, ... r = rasio konstan r ≠ 0

📐 Rumus Penting

1. Suku ke-n (Uₙ)

Uₙ = a · r(n-1)

2. Jumlah n suku pertama (Sₙ)

Jika r ≠ 1 → Sₙ = a · (rⁿ − 1) / (r − 1)
Jika r = 1 → Sₙ = n · a

3. Jumlah deret tak hingga (S∞) — hanya untuk |r| < 1

S∞ = a / (1 − r)

Keterangan:

  • a = suku pertama
  • r = rasio (perbandingan dua suku berurutan)
  • n = banyak suku

💡 Cara Mencari Rasio (r)

r = U₂ / U₁ = U₃ / U₂ = Uₙ / Uₙ₋₁

Rasio selalu konstan di setiap pasang suku berurutan.

🔑 Sifat-Sifat

  • Jika r > 1: suku terus membesar (divergen)
  • Jika 0 < r < 1: suku terus mengecil (konvergen)
  • Jika r < 0: suku berganti tanda (alternating)
  • Deret tak hingga konvergen hanya jika |r| < 1

👁 Visualisasi Barisan

📝 Contoh 1 — Suku ke-n

Barisan geometri: 2, 6, 18, 54, ...

Tentukan suku ke-6!

a = 2, r = 6/2 = 3
U₆ = 2 × 3(6−1) = 2 × 3⁵ = 2 × 243 = 486

Jadi suku ke-6 adalah 486

📝 Contoh 2 — Jumlah Suku

Barisan geometri: 3, 6, 12, 24, ...

Hitung jumlah 5 suku pertama!

a = 3, r = 2, n = 5
S₅ = 3 × (2⁵ − 1) / (2 − 1)
S₅ = 3 × (32 − 1) / 1
S₅ = 3 × 31 = 93

Jadi jumlah 5 suku pertama adalah 93

📝 Contoh 3 — Deret Tak Hingga

Diketahui: a = 8, r = 1/2

Hitung jumlah deret tak hingga!

|r| = 0.5 < 1 → konvergen ✓
S∞ = 8 / (1 − 0.5)
S∞ = 8 / 0.5 = 16

Jadi S∞ = 16

📝 Contoh 4 — Mencari Rasio

Suku pertama barisan geometri adalah 4 dan suku ke-4 adalah 108. Tentukan rasio!

U₄ = a · r³
108 = 4 · r³
r³ = 27
r = 3

Jadi rasio barisan tersebut adalah 3

📝 Contoh 5 — Mencari Banyak Suku (n)

Diketahui suku pertama barisan geometri adalah 2 dan rasionya 3. Jika nilai suku terakhir (Uₙ) adalah 162, tentukan banyak sukunya (n)!

Uₙ = a · r(n-1)
162 = 2 · 3(n-1)
162 / 2 = 3(n-1)
81 = 3(n-1)
3⁴ = 3(n-1)
n − 1 = 4
n = 5

Jadi, banyak suku dalam barisan tersebut adalah 5
